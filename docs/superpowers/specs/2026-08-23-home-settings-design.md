# 魔女炼金首页与设置菜单设计

## 目标

为现有水排序关卡增加一个真正的游戏首页和统一设置菜单。玩家可以从关卡返回首页而不丢失当前局面，并通过一个总声音开关同时控制背景音乐与全部游戏音效。

## 设计原则

- 延续现有暗调、紫金、Q 版魔女炼金美术，不照搬参考游戏的甜品主题或功能入口。
- 首页参考“顶部信息 + 中央主视觉 + 底部大按钮”的结构，保持单一视觉焦点。
- 只展示当前版本真实可用的功能，不加入礼包、排行榜、收藏等占位入口。
- React 原型继续作为视觉与交互验证目标；后续 Cocos Creator 工程以场景或界面层复刻同一状态流。

## 首页

首页沿用魔法炼金房间背景。Q 版魔女在中央区域播放等待动画，炼金锅与漂浮药水构成主视觉。

顶部显示：

- 游戏标题“魔女炼金屋”；
- 当前关卡“第 12 关”；
- 当前炼金进度，例如“魔药 8/8”；
- 右上角设置齿轮按钮。

底部仅保留一个大型紫金主按钮：`继续炼金 · 第 12 关`。点击后回到保留中的关卡局面。

## 关卡与首页状态流

原型使用一个顶层场景状态在 `home` 与 `level` 之间切换，不引入完整路由。

- 首次打开显示首页。
- 点击“继续炼金”进入关卡。
- 从设置菜单点击“返回主页”切换到首页。
- 返回首页不会重新创建关卡，不改变瓶子内容、瓶子位置、步数、已完成数量、奖励空瓶状态或撤销历史。
- 关卡组件的状态所有权保持在同一顶层生命周期内。视觉反馈计时器可以正常收尾，但首页不会接受关卡输入。
- 再次进入关卡时恢复离开时的稳定局面。

## 设置入口与弹窗

首页和关卡页右上角均使用同一个 48×48 齿轮设置按钮。点击后显示居中的紫金 Q 版设置弹窗，并以半透明暗色遮罩压暗背景。

弹窗内容仅包含：

1. 标题“设置”；
2. 一个“声音”总开关；
3. “返回主页”按钮；
4. 右上角关闭按钮。

在首页打开设置时，“返回主页”按钮隐藏或禁用，避免无意义操作。点击遮罩、关闭按钮或按 Escape 均关闭弹窗；关闭过程中遮罩持续拦截点击，不能穿透到瓶子或首页主按钮。

## 声音行为

界面只暴露一个声音总开关。

- 开启：背景音乐和游戏音效同时开启。
- 关闭：背景音乐和游戏音效同时关闭。
- 状态本地持久化，重新打开游戏后保持上次选择。
- 现有底层音频导演仍可保留音乐与音效两个轨道，以便分别设置音量、并发限制和完成音效压低音乐；总开关只是在界面层同时更新两个轨道。
- 音频文件加载或播放失败不影响首页、设置或游戏状态。

## 视觉资产

- 设置按钮使用新的齿轮位图，不能使用 emoji、文本符号、内联 SVG 或 CSS 绘制图标。
- 设置弹窗使用紫金炼金风格的真实位图面板，可复用已生成的音频设置素材作为风格基础，但需适配居中大弹窗比例。
- 总声音开关使用明确的“声音开启/静音”位图状态，并同时通过文字和 `aria-pressed` 表达状态。
- 首页主按钮与现有紫金按钮、message panel、魔女帧动画保持同一轮廓、材质与光照语言。

## 可访问性与交互

- 设置按钮名称为“打开设置”，并提供 `aria-expanded` 与 `aria-controls`。
- 弹窗使用 `role="dialog"`、`aria-modal="true"` 和可读标题。
- 打开后焦点进入弹窗；Escape 关闭后焦点回到设置按钮。
- 总声音开关的读屏名称为“声音：已开启”或“声音：已关闭”。
- 首页主按钮、设置按钮、关闭按钮、声音开关和返回主页按钮均具有至少 44px 的点击区域。
- `prefers-reduced-motion` 下关闭弹窗与首页切换的位移动画，但保留状态变化。

## 测试与验收

- 单元测试验证总声音开关同时更新音乐和音效偏好，并正确持久化。
- 组件测试验证设置弹窗的打开、关闭、焦点、Escape、遮罩拦截、首页按钮状态和可访问性标签。
- 集成测试验证返回首页后关卡瓶子、步数、完成数量和撤销历史保持不变，再进入后继续原局面。
- 浏览器 QA 覆盖 393×852 与 427×952，检查设置弹窗不越过安全边缘，首页主视觉不裁切，背景请求与音频请求无错误。
- 最终听感流程验证：总声音关闭后 BGM/SFX 均停止，重新开启后只恢复一个 BGM 实例，游戏状态不受影响。

## 非目标

- 本轮不加入每日礼包、排行榜、收藏品、体力、货币、振动、跳关或真实广告 SDK。
- 本轮不接入 CloudBase，也不创建真实账号或云端首页数据。
- 本轮不重写纯水排序引擎，不改变关卡种子、瓶子规则、完成消失时序或奖励空瓶规则。
