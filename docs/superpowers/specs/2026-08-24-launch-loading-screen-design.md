# 《暮影炼金室》启动加载页设计

## 目标

在 Cocos Creator 3.8.8 微信小游戏工程启动时，先显示一个与现有炼金室美术一致的加载页，再进入首页。加载进度必须来自真实资源预加载，不能用定时器伪造；资源失败时必须允许玩家重试，不能静默进入资源不完整的首页。

本轮只调整生产工程 `wechat-game` 的启动体验，不修改 React 原型的运行结构，不改变水排序规则、关卡数据、解锁进度或云端协议。

## 已确认的产品约束

- 设计分辨率保持 `393×852`，继续使用暗色炼金室背景、紫金配色、Q 版女巫和现有思源宋体资源。
- 左上角显示简洁的“8+”适龄提示。
- 中上部显示艺术字体标题“暮影炼金室”。
- 中央女巫播放现有 idle 动画，周围保留少量与药水粒子语言一致的环境粒子。
- 底部显示真实资源加载进度条和整数百分比。
- 启动页从首次可见开始至少展示约 `900ms`；加载完成且最短展示时间满足后，用 `220ms` 淡出进入首页。
- 最下方只显示标准健康游戏忠告。
- 不复制或伪造参考图中的公司名称、ISBN、审批文号、出版单位或软件著作权信息。
- 资源加载失败时显示明确错误状态和“重新加载”按钮。

## 方案选择

采用“单场景启动门控”方案：保留现有 Cocos 启动场景，由 `ProductionBootstrap` 先创建启动页，再通过 `resources.preloadDir('game')` 预加载游戏资源。只有资源加载成功和最短展示时间两个条件都满足，才初始化首页显示并启动云同步。

不新增第二个 Cocos 场景。第二场景会引入场景切换、常驻音频节点和状态转移的额外复杂度，而当前工程全部界面都由同一 `ProductionBootstrap` 组织。也不使用假进度或只预载少量关键图片，因为这两种做法都不能保证玩家进入首页时完整资源已经可用。

## 架构边界

启动加载状态属于 `assets/scripts/presentation/`：它控制 Cocos 资源回调、计时器、节点、动画和场景呈现，不进入纯规则层 `core`，也不访问微信 API。

新增一个不依赖 `cc` 的启动状态模块，例如 `presentation/launch-loading.ts`，负责：

- 将 `finished/total` 归一化为 `0..1`；
- 生成 `0..100` 的显示百分比；
- 维护 `loading`、`failed`、`ready`、`exiting` 四种状态；
- 判断“资源成功”和“最短展示时间满足”是否同时成立；
- 用加载尝试编号忽略过期回调，保证重试幂等。

`ProductionBootstrap` 仍是启动协调者，负责调用 Cocos API、创建启动页节点、启动计时器和最终进入现有首页。启动页不改变 `SceneFlowState` 的公开场景枚举，避免把一次性的应用启动阶段混入可返回的首页/关卡导航状态。

## 启动生命周期

`ProductionBootstrap.start()` 按以下顺序执行：

1. 设置 `393×852` 设计分辨率。
2. 读取本地全局进度、当前关卡、关卡快照和声音偏好。这些同步本地操作不受网络影响。
3. 立即创建并渲染启动页，记录首次可见时间，同时让全屏节点拦截输入。
4. 初始化本地音频状态、奖励和平台生命周期依赖，但不开始云进度同步。
5. 调用 `resources.preloadDir('game', onProgress, onComplete)`。进度回调只更新既有进度条和百分比节点，不销毁或重建整张启动页。
6. 资源加载成功后将显示值固定为 `100%`。如果距离首次可见不足 `900ms`，等待剩余时间。
7. 两个条件均满足后进入 `exiting`，在 `220ms` 内淡出整个启动页；淡出期间继续拦截输入。
8. 淡出完成后销毁启动页，调用现有首页渲染入口，并在首页已可用后启动第一次 `syncCloudProgress()`。

云同步延后到首页出现之后，防止网络请求与首屏资源加载竞争，也确保离线玩家可以正常进入本地首页。前后台生命周期绑定仍在启动阶段完成；如果启动过程中进入后台，回到前台后继续当前加载，不额外创建预加载请求。

## 真实进度规则

进度条只由 Cocos `preloadDir` 的 `finished` 和 `total` 驱动：

- 加载过程中使用 `clamp(finished / total, 0, 1)`。
- `total <= 0` 且尚未收到成功完成回调时显示 `0%`，避免除零和虚假完成。
- 每次加载尝试内的可见进度只增不减，防止依赖发现导致总数变化时进度条回跳。
- 加载中的整数百分比使用向下取整并封顶 `99%`；只有成功完成回调可以显示 `100%`。
- 超界、非有限数或重复回调都要被归一化，不得产生负宽度、超过容器的宽度或二次转场。

启动页所用背景、字体和女巫帧也位于 `game` 资源目录。它们可通过现有 `resources.load` 帮助函数并行取得并逐步替换启动页的基础占位呈现；这些请求会命中同一资源缓存。最终进入首页仍以整个 `game` 目录预加载成功为唯一资源就绪条件。

## 视觉布局

启动页根节点覆盖完整设计画布，并使用 `BlockInputEvents`。坐标以画布中心为原点：

- 背景：现有炼金室背景铺满 `393×852`，叠加低透明深紫遮罩，保证文字与进度清晰。
- 适龄提示：左上安全区内约 `42×42` 的圆角深紫金边徽标，显示“8+”，不附带虚构备案信息。
- 标题：中上部约 `y=235`，使用现有思源宋体艺术化排版、暖金主色、深紫描边和轻微柔光，正文固定为“暮影炼金室”。
- 主视觉：女巫位于画面中央，使用现有 idle 帧动画；周围配置少量确定性循环的紫、青、金药水粒子，复用已建立的粒子轨迹语言，避免每次启动随机跳位。
- 加载条：位于底部约 `y=-230`，宽约 `300px`。外框使用紫金面板风格，内部填充从左向右增长，百分比位于加载条下方。
- 忠告：置于最下方安全区，使用小号但可读的浅灰紫文字，内容为“抵制不良游戏，拒绝盗版游戏。注意自我保护，谨防受骗上当。适度游戏益脑，沉迷游戏伤身。合理安排时间，享受健康生活。”可排为两至三行。

首帧即使个别位图尚未回调，也必须有深紫底色、标题、进度框和状态文字，不能出现透明画布或黑屏。字体资源可用后原位替换字体，不触发整页重建。

## 错误与重试

`preloadDir` 完成回调返回错误时，启动页进入 `failed`：

- 停止自动进入首页，保留炼金室背景和女巫主视觉。
- 加载条区域改为“资源加载失败，请检查网络或存储空间”。
- 显示一个与现有长按钮一致的九宫格“重新加载”按钮。
- 失败状态下只有重试按钮可交互，其余区域继续被遮罩拦截。

点击重试会立即禁用按钮、增加加载尝试编号、重置本次可见进度并重新调用 `preloadDir('game')`。旧尝试的迟到回调因编号不匹配而被忽略；连续点击不会创建多个并发重试。最短 `900ms` 以启动页首次可见时间计算，不在每次重试时重新计时。重试成功后执行同一个 `100% → 淡出 → 首页` 流程。

如果单独的启动页装饰资源加载失败，但目录预加载最终成功，则以目录完成结果为准；首页使用现有资源加载失败降级行为。任何错误都不得清除本地进度或当前关卡快照。

## 与现有系统的关系

- 首页、选关、关卡、完成页和设置页的布局及状态流保持不变。
- 本地存档仍在启动时读取；加载失败或重试不会写入、迁移或删除进度。
- 第一次云同步从启动阶段移动到首页呈现之后；后续前台恢复同步逻辑不变。
- 声音偏好仍在本地读取。启动页不强制播放音频，也不绕过微信的首次手势解锁要求。
- 启动页使用现有背景、女巫、按钮、字体和粒子资源，不引入另一套割裂的美术，也不从未批准素材目录复制文件。
- 第一章 1–15 关、固定 5×3 棋盘、奖励空瓶和关卡快照契约不受影响。

## 测试策略

先写失败测试，再实现状态和呈现：

1. 纯函数测试覆盖 `0/0 → 0`、中间进度、成功完成、负数、超过总数、非有限数和进度不回退。
2. 状态测试验证只有“资源成功 + 已展示 900ms”同时成立才允许退出。
3. 状态测试验证失败后不能进入首页，`失败 → 重试 → 成功` 能正常完成。
4. 状态测试验证重复完成回调、过期尝试回调和连续重试不会产生二次淡出或多个有效加载尝试。
5. 生产契约测试验证启动时真实调用 `resources.preloadDir('game')`，且首页渲染和第一次云同步都在预加载成功之后发生。
6. 呈现布局测试验证适龄提示、Logo、女巫、加载条、百分比、忠告和失败按钮均处于 `393×852` 安全区域。
7. 回归运行微信端完整 TypeScript 测试和原型保护测试，确保现有粒子、字体、关卡、存档、音频与按钮契约不变。
8. 使用 Cocos Creator 3.8.8 执行微信小游戏构建，检查构建日志完成、资源目录可解析、启动页无脚本序列化警告，并保留 Creator 生成的 `.meta`。

## 验收标准

- 冷启动第一帧不是黑屏，启动页视觉与现有暗紫金炼金室一致。
- 百分比来自真实 `game` 目录预加载，加载中不回退、不提前显示 `100%`。
- 快速缓存命中时启动页仍至少可见约 `900ms`；随后在约 `220ms` 内淡出。
- 加载完成前、失败状态和淡出期间都不能误触首页或关卡按钮。
- 加载失败有可见错误和可重复使用的重试路径；成功重试只进入首页一次。
- 进入首页后本地进度、当前关卡、声音偏好及现有交互均保持正确，云同步不会阻塞首屏。
- 页面不展示任何虚构公司、ISBN、审批号或出版信息。

## 非目标

- 不加入账号登录、公告、更新下载、版本热更、隐私授权弹窗或渠道审核信息。
- 不新增第二套启动美术，不生成新的公司 Logo 或出版标识。
- 不改造 React 原型为正式加载器。
- 不扩展第一章关卡数量，也不在本轮设计第二章、章节选择或存档上限迁移。
- 不在运行时生成或求解关卡。
